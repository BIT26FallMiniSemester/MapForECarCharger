# PC 管理端测试记录模板

| 编号 | 场景 | 操作 | 预期结果 |
|---|---|---|---|
| A01 | 演示登录成功 | 勾选演示模式，输入 `admin/123456` | 进入运营首页 |
| A02 | 登录失败 | 输入错误密码 | 显示统一账号密码错误，不泄露账号是否存在 |
| A03 | 后端不可用 | 关闭演示模式并填写不可达地址 | 显示无法连接服务，程序不退出 |
| D01 | 7/30 日趋势 | 切换趋势周期 | 请求对应 days，日期连续补零 |
| D02 | 状态分布 | 查看首页环形图 | 展示五种枚举的数量和占比 |
| P01 | 电桩组合筛选 | 选择站点、状态并输入编号 | 请求参数正确，结果分页显示 |
| P02 | 故障重启 | 对 `FAULT` 电桩点击重启并确认 | 成功后刷新为 `IDLE` |
| P03 | 非法重启 | 对 `CHARGING/OFFLINE` 电桩重启 | 客户端拦截或后端返回冲突 |
| S01 | 新增站点 | 输入合法名称、地址、坐标和电价 | 新增成功并刷新列表 |
| S02 | 坐标校验 | 输入超出经纬度范围的值 | 控件限制在合法范围 |
| S03 | 新增重复电桩 | 输入已经存在的编号 | 显示编号重复错误 |
| U01 | 手机号查询 | 输入手机号片段 | 返回匹配用户，列表手机号脱敏 |
| U02 | 冻结正常用户 | 选择无活动订单用户并确认 | 状态变为 `FROZEN` |
| U03 | 冻结冲突 | 选择存在活动订单的用户 | 显示“存在未完成订单”且状态不变 |
| U04 | 幂等操作 | 重复冻结或解冻 | 后端按成功返回，不产生重复副作用 |

测试环境、执行时间、实际结果和截图可在联调后继续补充。
