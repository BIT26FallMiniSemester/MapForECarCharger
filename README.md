# MapForECarCharger

电动汽车充电桩应用管理平台课程项目，面向充电用户、运营管理员和数据分析人员，提供充电站查询、预约充电、订单结算、设备管理、运营统计和负荷预测等功能。

## 项目模块

- 用户端：基于 Qt/C++，提供登录、站点查询、预约充电、订单结算和个人信息管理。
- 管理端：基于 Qt/C++，提供站点、电桩、用户和营收管理。
- 后端服务：提供统一 API、业务逻辑、权限校验、数据存储和模拟充电桩服务。
- Web 大屏：基于 ECharts 展示营收、订单、设备状态和站点运行情况。
- 数据分析：基于历史或模拟数据进行充电负荷预测和站点推荐。

## 核心业务流程

```text
用户登录
→ 查询充电站
→ 查看空闲电桩
→ 预约充电
→ 开始充电
→ 结束充电
→ 订单结算
→ 管理端和大屏同步展示数据
```

## 初步技术方案

- 开发与运行环境：Ubuntu Linux
- 用户端、管理端：Qt 6 / C++
- 后端：FastAPI / Python
- 数据库：SQLite，后续可根据需要迁移至 MySQL
- Web 大屏：ECharts
- 通信方式：HTTP/REST + JSON
- 代码管理：Git，采用功能分支开发并合并到 `develop`，稳定版本进入 `main`
