# Qt 用户端

用户端通过带长度头的 JSON TCP Socket 连接 `server-qt`，不直接访问 SQLite，也不保存腾讯地图 Key。

## 构建和运行

```bash
cd ~/MapForECarCharger/clients/user-qt
sudo apt install qt6-webengine-dev
qmake6 charging-user-client.pro
make -j$(nproc)
./charging-user-client
```

默认后端为 `127.0.0.1:9000`。测试用户为 `13900000000`，运行库不再创建其他模拟用户。

窗口默认使用 `410 × 820` 的手机比例，并限制在 `390–440` 像素宽；地图保持 2:1 比例，列表在独立区域内滚动。

## 演示流程

1. 登录 `13900000000`，在“我的”页面按需充值。
2. 首页修改位置；可选北京区域，也可输入地址由后端调用腾讯地图解析。
3. 首页显示紧凑的腾讯地图、当前位置和编号站点标记；列表按腾讯地图驾车路线距离排序。
4. 地图可围绕选中站点放大或缩小；点击地图点或整张站点卡会双向高亮并显示原始经纬度。
5. 点击卡片中的距离可在 Qt WebEngine 中切换驾车/步行路线，并可调起腾讯地图导航；站点卡只保留“去充电”主按钮。
6. 初始化后所有真实站点都有空闲受管电桩，“去充电”均可进入充电页。
7. 客户端创建订单并自动预约；用户点击“开始充电”。
8. “充电”页每两秒向后端查询时长、电量和金额。
9. 结束充电生成待支付账单，再使用余额付款。
10. 重新打开客户端会提示未完成订单并自动进入充电或结算页。
